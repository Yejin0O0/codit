## tdd-loop 재개 기능

**배경**: 현재 tdd-loop 실행 중 실패하면 해당 스킬을 직접 실행해서 재개해야 한다. 세션이 길어지거나 팀원이 이슈를 이어받을 때 "어느 단계까지 완료됐는지" 기억하거나 찾아야 하는 불편함이 있다.

**개선 방향**: tdd-loop가 각 단계 완료 시 `issue-{N}.md`에 상태를 기록하고, 재실행 시 완료된 단계를 자동으로 스킵해 실패 지점부터 재개. `/tdd-loop {이슈번호}` 하나로 재개 가능해진다.

## 대시보드 작업 전 스킬 업그레이드

**배경**: 통계 대시보드는 복잡한 필터 조합, 차트별 독립 loading/error 상태, 드릴다운 흐름이 생긴다. 현재 스킬은 단순 CRUD Feature 기준으로 설계되어 있어 대시보드에 그대로 적용하면 설계·구현 품질이 부족하다.

**업그레이드 시점**: 대시보드 Feature prd.md 작성 직후, 첫 이슈 작업 전.

| 스킬 | 추가할 내용 |
|------|-----------|
| `fe-ui-design` | 복잡한 UI 감지 시 State Machine 전환 옵션 (필터 조합, 드릴다운, 차트별 독립 상태) |
| `test-scenarios` | 데이터 페칭 상태·페이지네이션·필터 조합 시나리오 패턴 |
| `tdd-green-frontend` | 차트 라이브러리 컴포넌트 테스트 패턴 (recharts 등) |
| `e2e-write` | 대시보드용 데이터 픽스처·mock API 전략 |
