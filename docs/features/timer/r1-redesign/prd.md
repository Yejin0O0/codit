# Timer 화면 재설계 — PRD (리디자인 브리프)

> Layer 2 R1. 에픽 #51 / 이슈 #54. R0(#52) 스택 위.
> `TimerScreen`·`TimerDisplay` **레이아웃만** 재설계 — props 시그니처·동작 로직 불변.

## 배경

R0에서 프레임(`PanelShell`)이 재설계됐다. Timer 화면 본문은 timer 기능 최초 구현 그대로다:
문제 라벨(작은 muted) → `00:00`(5xl) → "측정 중"(작은 muted), 중앙 스택에 빈 공간 많음.

## 사용자 스토리

- **US-1** 위젯을 볼 때, 지금 어느 문제를 재고 있는지 헤더에서 바로 안다.
- **US-2** 경과 시간이 화면의 명확한 초점이다.
- **US-3** 타이머가 "돌고 있다"는 것이 시각적으로 드러난다 (정지 화면이 아님).

## 결정 (스파이크에서 개발자 확정)

| 항목 | 결정 |
|------|------|
| 헤더 | **문제 제목을 헤더 title 로** — `풀이 타이머` 라벨 제거. `problemTitle` 없으면 `문제 #{id}` 폴백 |
| 본문 문제 라벨 | **제거** (헤더로 이동) |
| 타이머 크기 | **7xl** (현재 5xl) |
| 러닝 표시 | **펄스 도트(민트) + "측정 중"** — 텍스트만 → 도트 동반 |
