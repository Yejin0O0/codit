# SWEA 호스트 사이트 감사 (Codit 위젯 공존 근거)

> 위젯은 SWEA 페이지 위에 `position: fixed`로 뜬다. Shadow DOM이 스타일을 격리해도
> **시각적으로는 SWEA UI 옆에 붙어** 보이므로, SWEA 팔레트와의 공존을 설계 제약으로 삼는다.
> 방법: 2026-09-07 실제 브라우저 캡처 + 픽셀 샘플링 (로그인 상태로 `solvingProblem.do` 포함).

---

## 위젯이 뜨는 페이지

- **`solvingProblem.do` 하나.** content script `matches`는 `*://swexpertacademy.com/*` 전역이지만
  `mountCoditWidget()`은 `resolveProblemId` 성공 시에만 마운트.
- 로그인 / 메인 / 문제 목록(`problemList.do`) / 문제 상세(`problemDetail.do`) = 위젯 안 뜸 → **디자인 대상 아님**
- `solvingProblem.do`는 URL에 `contestProbId` 없음 → hidden input에만 존재

---

## `solvingProblem.do` 레이아웃

- 세로 1열 스크롤. 좌측 얇은 사이드바(제출결과) + 본문(문제 지문 → 코드 에디터 → TEST 패널 → 제출 버튼)
- 상단바: near-black 얇은 띠 ("SW Expert Academy 모의 테스트")
- 위젯은 우상단 fixed → 스크롤에 따라 문제 지문 / 코드 에디터 / TEST 패널 위에 겹침. **전부 흰색 계열.**

## Codit 설계 제약 (여기서 도출)

1. **Codit `--primary` hue ∉ [190°, 235°]** — SWEA 파랑(`#4590E3`, 212°) 회피. 같은 파랑이면 "SWEA 기본 패널"로 오인.
2. **위젯은 `#FFFFFF` 위에 뜬다.** 표면 분리를 강제:
   - 라이트 위젯 → 강한 그림자 + 뚜렷한 보더 + (선택) 미세 틴트
   - 다크 위젯 → 최대 대비. **에디터가 라이트 테마라 다크 위젯이 묻히지 않음 (검증됨)**
3. **에디터 syntax 하이라이트가 보라.** Codit primary를 순보라(~290°)로 하면 살짝 rhyme → **인디고(~255~265°)** 권장.
4. **타이머 도중 = 사용자가 코드에 집중하는 시간.** idle 위젯은 저채도·무애니메이션·여백 넉넉히. 강한 색은 상호작용 요소(결과 선택 등)에만.
5. **semantic 초록/빨강**은 채운 pill + 흰 텍스트로 SWEA 파스텔 난이도 배지와 구분. (위젯이 문제 목록엔 안 떠서 우선순위 낮음)
6. SWEA는 이 페이지에서 성공 표시에 **파랑**(`#2599E0`)을 씀 — Codit이 성공=초록을 써도 문맥이 분리돼 충돌 아님.

## 재감사 방법 (`/design-system audit`)

`solvingProblem.do` 한 페이지만 로그인 상태로 캡처 → 위 값 대조. SWEA가 리뉴얼하면 `--primary` hue 회피 밴드만 갱신.
